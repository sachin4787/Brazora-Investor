# Brazora Hair & Skincare — GitHub Pages Website

A responsive single-page website inspired by the supplied Brazora reference design and presentation assets.

## Publish on GitHub Pages

1. Create a new GitHub repository, e.g. `brazora-website`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/root`.
4. Save. GitHub will provide the public Pages URL.

## Replace the enquiry form

The contact form is currently front-end only. Connect it to Formspree, Netlify Forms, your CRM, or a backend endpoint before using it for live enquiries.

## Assets

The website uses optimized WebP versions of the supplied Brazora presentation visuals.
